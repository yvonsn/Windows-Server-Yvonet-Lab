# Conclusiones

## Objetivo alcanzado

El laboratorio **Windows Server YVONET** permitió implementar y documentar una infraestructura básica de red basada en Windows Server y un equipo cliente Windows 11, ambos virtualizados mediante VirtualBox.

Durante el proyecto se configuró el dominio **YVONET.LOCAL** mediante Active Directory, organizando usuarios y recursos para simular un pequeño entorno empresarial.

La implementación incluyó la configuración de Active Directory Domain Services, DNS, Unidades Organizativas, usuarios del dominio, recursos compartidos y permisos NTFS, así como la realización de pruebas desde el equipo cliente.

## Conocimientos aplicados

Durante el desarrollo del laboratorio se trabajó con:

* VirtualBox
* Windows Server
* Windows 11
* Active Directory Domain Services (AD DS)
* DNS
* Unidades Organizativas (OU)
* Administración de usuarios
* Recursos compartidos
* Permisos NTFS
* Configuración básica de red

## Competencias desarrolladas

El proyecto permitió poner en práctica conocimientos relacionados con:

* Instalación y configuración de Windows Server.
* Creación y administración de un dominio de Active Directory.
* Organización de usuarios mediante Unidades Organizativas.
* Incorporación de equipos cliente al dominio.
* Administración de usuarios y recursos de red.
* Configuración y comprobación de permisos NTFS.
* Gestión de carpetas y recursos compartidos.
* Diagnóstico y resolución de incidencias.
* Documentación técnica de procedimientos.

## Aprendizajes

Uno de los principales aprendizajes del laboratorio fue comprobar que la administración de sistemas no consiste únicamente en aplicar configuraciones, sino también en verificar su funcionamiento, identificar posibles errores y realizar un diagnóstico ordenado hasta encontrar su causa.

Las incidencias encontradas durante la configuración de VirtualBox y de los permisos permitieron poner en práctica este proceso de resolución de problemas.

La documentación del laboratorio también ha permitido registrar tanto las configuraciones realizadas como las soluciones aplicadas, creando una referencia que puede utilizarse para reproducir o ampliar el entorno en el futuro.

## Posibles mejoras futuras

El laboratorio puede ampliarse incorporando nuevas funcionalidades y servicios, entre ellos:

* Directivas de Grupo (GPO).
* Servicio DHCP.
* Automatización de tareas mediante PowerShell.
* Políticas de contraseñas y seguridad.
* Copias de seguridad y recuperación.
* Servidor de impresión.
* Monitorización del servidor.
* Administración de permisos mediante grupos de seguridad.

## Conclusión final

El proyecto **Windows-Server-YVONET-Lab** representa la implementación funcional de un entorno básico de Windows Server orientado a la práctica de administración de sistemas.

El laboratorio ha permitido recorrer diferentes fases de una infraestructura de dominio: desde la virtualización e instalación inicial hasta la configuración de Active Directory, DNS, usuarios, equipos cliente, recursos compartidos y permisos.

El resultado es un entorno de laboratorio operativo y documentado que sirve como demostración práctica de conocimientos básicos de **Windows Server, Active Directory, redes y soporte IT**, y que puede seguir ampliándose progresivamente con nuevos servicios y herramientas de administración.
